GTC AFRICAN STYLE – WEBSITE
=============================

Arquivos:
- index.html       Website principal
- admin.html       Painel simples para editar conteúdo no navegador
- styles.css       Design responsivo
- app.js           Interações, idioma e assistente
- assets/gtc-logo.png
- assets/gtc-founder.jpg

COMO ABRIR:
1. Extraia a pasta.
2. Abra index.html no Chrome/Edge.
3. Para editar, clique em "Editar site" ou abra admin.html.
4. As alterações do painel ficam guardadas no navegador (localStorage).
